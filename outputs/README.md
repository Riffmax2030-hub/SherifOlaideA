# Sherif Akanmu - Portfolio Website

A modern, responsive portfolio website for Sherif Akanmu, an AI-focused Full-Stack Developer based in Doha, Qatar.

## Features

- **Modern Design**: Clean, minimalist aesthetic with smooth animations
- **Responsive**: Fully responsive design that works on all devices
- **Smooth Animations**: GSAP animations, scroll reveals, and magnetic effects
- **Dark Mode Ready**: Easy to extend with dark mode support
- **Custom Cursor**: Desktop-only animated custom cursor
- **Mobile Menu**: Optimized mobile navigation menu
- **Contact Form**: Integrated contact form for inquiries

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **CSS Framework**: Tailwind CSS
- **Animations**: GSAP, CSS animations
- **Icons**: Lucide Icons
- **Fonts**: Google Fonts (Inter, Space Grotesk)

## Project Structure

```
├── index.html       # Main HTML file
├── styles.css       # Custom CSS styles
├── script.js        # JavaScript functionality
├── package.json     # Project metadata
├── vercel.json      # Vercel deployment config
└── .gitignore       # Git ignore rules
```

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```

2. Install dependencies (optional, for local development):
```bash
npm install
```

3. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
# or
npx http-server
```

## Deployment

### Vercel (Recommended)

1. Push your code to GitHub
2. Sign in to [Vercel](https://vercel.com)
3. Click "New Project"
4. Import your GitHub repository
5. Click "Deploy"

Your site will be live in seconds!

### Netlify

1. Push your code to GitHub
2. Sign in to [Netlify](https://netlify.com)
3. Click "New site from Git"
4. Connect your GitHub repository
5. Click "Deploy site"

## Customization

- **Colors**: Edit CSS variables in `styles.css`
- **Content**: Update text in `index.html`
- **Images**: Replace image URLs with your own
- **Social Links**: Update social media URLs in the contact section
